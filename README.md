1. Storage and Accessibility

Efficient storage and organisation let team members quickly find the correct, most recent version of a file, avoiding duplicated work and outdated data. It also supports reproducibility and data integrity when files need to be traced, shared, or archived.

2. File Storage Methods

Non-sensitive files like literature, scripts, and drafts can be stored in a GitHub repository or shared drive for easy collaboration. Interview transcripts, consent forms, and identifiable photos are sensitive data that need special access controls and should be kept in a secure system such as UQ RDM, not a public repository.

3. Why is it important to have a good naming convention?

A consistent naming convention lets files be identified by name alone, so collaborators can find the right version quickly without confusion. It also keeps files sortable and avoids spaces or special characters that can break paths across different systems.
